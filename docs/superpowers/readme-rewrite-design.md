# MomentWebStitcher README 重写规格

## 目标

重写根目录 README，使首次访问者能快速理解项目用途、当前能力和本地运行方式，并通过真实界面截图看到完整操作流程。

## 信息架构

1. 项目标题、状态徽章、在线地址与一句话定位。
2. 一张真实主界面截图，展示当前奶油色双栏布局。
3. 核心特性：浏览器本地处理、批量上传、EXIF 时间排序、自动/手动分组、鼠标与触屏拖拽、迷你预览、全屏预览、结果卡片批量保存。
4. 快速开始：在线使用、本地静态服务器运行、开发测试命令。
5. 使用流程：上传图片、调整分组、预览拼接结果、保存文件；配合 4 张真实工作流截图。
6. 输出规则与兼容性：垂直拼接、宽度上限 1080 px、质量 70%～100%、支持格式与 HEIC 说明。
7. 技术实现、项目结构、部署和贡献入口。
8. 常见问题与许可证。

## 配图方案

- 图片放在 `docs/images/`，使用 PNG，全部通过相对路径引用。
- `app-empty.png`：空状态主界面，作为首屏产品图。
- `app-grouped.png`：上传多张图片并自动分组后的工作区。
- `app-preview.png`：全屏长图预览浮层，展示输出尺寸。
- `app-result.png`：拼接完成后的结果卡片，展示单组保存与全部保存。
- 每张图片提供描述性 alt 文本；README 不依赖 GitHub 外链附件。
